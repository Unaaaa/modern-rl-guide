# 附录C：现代优化与多主体训练伪代码

以下为机制示意，省略梯度累积、分布式同步与数值稳定细节，不是可直接运行的训练程序。

```text
固定本轮行为策略 old
按任务采样候选轨迹，保存行为概率与版本
由验证器评分，按可比较上下文组织样本
根据所选方法计算优势与权重
仅在属于策略动作的位置聚合损失
有限轮更新当前策略；监测 KL、熵与有效样本
在独立任务上评价；随后刷新行为策略
```

多角色扩展还要明确 `role → policy_parameters` 映射，保存父轨迹和角色轮次；不能将不同角色的数据无条件混为一个相对奖励组。MAPPO 的集中价值输入与执行 Actor 的局部输入应分别维护。
