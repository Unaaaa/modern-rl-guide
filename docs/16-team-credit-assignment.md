# 第16章 团队奖励、个体贡献与信用分配

> 读前回顾：[第14章](14-multi-agent-modeling.md) · [第15章](15-marl-algorithms.md)

规划者把任务分得很漂亮，执行者漏了一个条件，检查者最后补救成功。团队拿到了奖励，这份奖励应该怎样影响三个角色？

最终分数告诉我们团队做得怎样，却没有直接说明每个角色该改什么。信用分配要填补的，正是这段距离。

## 16.1 团队奖励为什么不够细

最简单的做法，是让规划、执行、检查三个角色都收到同一份团队奖励。这可以作为训练基线，却容易模糊两种情况：是规划本来就正确，还是检查者救回了错误？要让每个角色更有针对性地更新，需要更细的比较。

共同奖励的长处是目标一致：每个角色都被鼓励提高最终团队表现。困难是同一分数同时包含队友能力、任务随机性和自己行为的影响。若规划者已经很好，执行者的随机失败仍会让规划者收到负反馈，更新方差可能较大。

直接改成各自奖励也有风险。执行者只追求工具成功，检查者只追求发现问题，可能分别做得很积极，却使团队反复交接。个体信号应帮助实现共同目标，而不是悄悄替换共同目标。

## 16.2 价值分解与反事实基线

价值分解尝试把团队价值表示成与个体有关的结构；反事实基线则追问：在队友动作不变时，这个角色的实际动作比它通常会选的其他动作好多少？COMA 用集中 Critic 估计这些价值，对候选动作作策略加权平均，再与实际动作比较。估计是否可信取决于 Critic，它不能直接充当真实因果贡献。[COMA](https://arxiv.org/abs/1705.08926v3)

反事实基线的好处，可以从“不相关变化”理解。若队友已经犯下无法补救的错误，当前主体各种动作的团队价值都低，减去其候选平均值后，信号可以更集中地反映动作之间仍存在的差别。

但候选动作价值并非都被真实执行。COMA 依赖 Critic 对它们作估计，罕见动作或未见组合仍可能估错。反事实计算形式精巧，并不使反事实预测自动可靠。

## 16.3 贡献估计的假设与代价

差分奖励比较“有该主体行为”与某个明确替代情景下的团队结果；Shapley 思想则考虑不同联盟中加入主体的边际贡献。二者都依赖反事实定义，后者通常还面临较高计算成本。

差分奖励需要明确替代行为。例如移除检查者，可以让团队直接提交，也可以让执行者承担检查职责；两个对照回答的不是同一个问题。前者测角色存在的作用，后者还改变了任务分配与资源使用。

Shapley 式边际贡献平均考虑不同加入顺序，能够减少对单一联盟选择的依赖，但计算量随组合增加。近似采样可以降低成本，同时引入估计误差。对大型 Agent 团队，贡献解释应报告采用的反事实与近似方式。

## 16.4 同时分析时间与角色

时间和角色构成两条归因轴：先问失败发生在哪一步，再问谁控制该决策。检查角色如果总在无关格式问题上获得奖励，可能增加轮次却不提高质量。可通过移除角色、固定其他角色、替换队友和回放关键分支，判断贡献解释是否经得起干预。

可以建立一张“角色×阶段”的错误表：规划阶段有没有遗漏条件，执行阶段是否取得必要证据，检查阶段是否识别冲突。先把失败定位到受控决策，再讨论怎样分配奖励。只有最终一列团队标签，通常不足以解释所有角色。

过程反馈最好关联可验证事实。例如检查者指出“时间范围不符”后，执行者确实修正并通过独立测试，这比奖励检查者写了多少条意见更有意义。贡献分析与奖励设计可相互帮助，但不应互相作为唯一证据。

## 16.5 反事实基线的数字例子

固定队友动作，假设 Critic 估计某主体两个候选动作的团队 Q 值为8和4，当前策略分别以0.25和0.75的概率选择它们。策略加权基线为 $0.25\times8+0.75\times4=5$；实际选择第一个动作时，估计优势为3。

这说明反事实基线能把动作放到可替代选择中比较，却不说明该主体“独自贡献了3分”：价值来自模型预测，且比较固定了队友动作。换一个反事实定义或队友策略，结果可能不同。

在这个数字例子里，若 Critic 把两个动作都误估为8，优势就会变为0；即使真实结果差异很大，学习器也看不到。这说明反事实基线依赖的不只是公式，还包括有区分力的价值估计。

实际复盘可以用可重放环境固定队友，真实执行几种替代动作，对估计排序作抽样验证。它不必覆盖全部动作，却能帮助判断 Critic 是否在关键决策上提供了错误方向。
