# 第17章 通信、分工与 LLM 多角色联合训练

> 读前回顾：[第07章](07-ppo-to-grpo.md) · [第14章](14-multi-agent-modeling.md) · [第16章](16-team-credit-assignment.md)

两个 Agent 交换了十轮消息，最后的答案却没有比单个 Agent 更好。问题可能不在于说得不够，而在于该传的信息没有传到，需要决定时又无人拍板。

通信、分工与停止协作，本身都是决策。要训练这些决策，还得解决一个更细的问题：哪些角色、哪些上下文中的输出，才适合放在一起比较？

## 17.1 把通信视为有成本的动作

一条消息也有行动成本：生成要花 token，等待会增加延迟，模糊的指令还可能让队友走错方向。因此，可学习的选择包括发给谁、何时发、发什么，以及何时结束交流。任务、证据引用、不确定性和交接条件，是值得优先传递的信息；通信评价也要计入轮次与延迟。

通信动作可分成内容与时机。内容相同，在证据尚未核验时发送，可能把不确定信息当成事实；在队友已经完成同样查询后发送，则可能没有价值。因此，训练目标需要考虑消息怎样改变后续行动，而不只是评价消息是否流畅。

可先固定消息结构，再学习何时发送与发给谁。例如只允许传递证据ID、状态和待解决问题，便于检查信息是否真实。待结构化方案明确受限后，再研究自由文本通信，有助于判断语言灵活性是否抵得上额外成本。

## 17.2 共享模型与独立策略

角色分开，并不要求权重也分开。一套 LLM 参数可以配合不同角色提示承担多种职责；也可以让各角色使用独立模型。前者节省权重资源，却可能出现梯度冲突；后者更便于专门化，也增加采样、同步和版本管理成本。

共享模型训练时，规划者与执行者的样本进入同一参数更新。若执行者轨迹远长于规划者，按 token 聚合可能使执行角色占据更多权重；按角色等权则会改变另一种尺度。两种做法都包含优化偏好，应在配置中明确。

独立策略还需要处理兼容性。规划者升级后输出更细的子任务，旧执行者可能无法识别；即使各自在单角色测试中变好，组合也可能退化。因此联合评估应记录完整策略组合，并保留跨版本队友测试。

## 17.3 多角色训练的研究案例

[MATPO，v1](https://arxiv.org/html/2510.04678v1)研究单一 LLM 内的规划者与执行者，将角色轨迹纳入训练并处理信用传播，实验覆盖工具与信息检索任务。这提供了共享模型多角色训练的案例，尚不能证明任意角色拆分都有效。

[Stronger-MAS / AT-GRPO，v5](https://arxiv.org/html/2510.11062v5)关注角色、轮次不同导致候选不可直接比较的问题，采用按主体与轮次组织的分组及树状采样，并覆盖共享和独立策略训练。关键启发是：**不能仅因几条轨迹属于同一个原始问题，就把不同角色、不同历史下的输出当作可交换候选。**

阅读这类研究时，先画出角色轨迹：谁产生子任务，谁访问工具，谁收到最终奖励，哪段输出进入哪套参数。然后再看分组和信用传播。角色同名，并不保证论文中的观测与控制范围相同。

还应分开系统结构与训练改动。多角色提示本身可能已经改善上下文组织；联合训练又可能带来额外收益。保留固定编排、单角色训练和共享训练的对照，才有机会解释二者分别贡献了什么。

## 17.4 分组、掩码与参数归属

工程上应记录每段输出的角色、上下文、父分支、奖励来源与目标参数。先在可恢复的相同上下文形成候选，再按对应方法回传优势；更新共享模型时还要检查角色样本失衡。MCP、A2A 一类互操作协议解决接口与协作连接问题，本身不提供策略学习或信用分配机制。

以一个独立执行者为例，它接到规划者消息后生成工具调用，再读返回值继续行动。执行者自己的生成位置参与策略损失，规划者消息和工具返回作为条件输入。若把整段拼接文本全部作为执行者动作，便会训练它去“预测”并不由它控制的外部结果。

对共享模型，队友输出可能在其原属角色的轨迹中参与训练，但仍需避免在不同样本中重复计权或错误归因。共享参数改变的是更新归属，不能消除行为来源的区分。

## 17.5 什么样的候选才适合比较

假设规划者在历史 $h_0$ 下产生两个委派方案，这两个方案可以作为同上下文候选；执行者收到不同委派后，面对的输入已不同，不能仅按角色名称把输出混成同一组。

一种组织方式是保存分支树：父节点标识上下文，子节点标识候选动作，后续轨迹提供回报。分组还需按角色与轮次追踪条件；采用具体论文方法时，应复核其奖励传播和分组定义。

对共享模型，每个角色生成的 token 都可在相应轨迹中成为动作；对某个独立角色而言，队友消息是环境输入，不应误算成该角色生成的动作。

分支采样还要求可恢复相同的比较条件。若候选一执行后已经改变环境，再从被修改的环境生成候选二，两者看到的就不是同一任务状态。只复制提示文字，而不恢复工具状态，也可能产生这种差异。

外部搜索任务难以严格复原时，应记录冻结结果、时间与不确定性，并承认比较条件的限制。更多分支会增加反馈质量，也会增加生成和环境成本；不能仅按最后留下的有效组核算。
