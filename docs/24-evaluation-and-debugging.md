# 第24章 评估、可观测性与训练排障

> 读前回顾：[第22章](22-experiment-design.md) · [第23章](23-training-systems.md)

奖励曲线一路上升，独立测试却没有改善。此时最需要的不是更漂亮的曲线，而是能解释差异的证据：评分是否失真，任务是否泄漏，策略是否只学会了捷径？

评估负责判断有没有进步，日志帮助解释为什么。把两者对照起来，排障才有方向。

## 24.1 从异常曲线定位问题

| 现象 | 优先检查的证据 | 可能的处理 |
| --- | --- | --- |
| 奖励升高，独立正确率下降 | 奖励漏洞、评审偏差、数据泄漏 | 修复评分器与测试隔离 |
| GRPO 大量零优势组 | 全对/全错比例、任务难度 | 调整课程或采样，核算额外成本 |
| 熵快速下降，输出同质化 | 长度、KL、优势尺度与裁剪 | 检查步长、权重与探索机制 |
| 多角色训练后更慢 | 通信量、重复查询、角色调用分布 | 减少无效交接，做角色消融 |
| 新策略只胜当前对手 | 历史交叉对战与留出对手 | 调整对手池与评估分布 |

排障可以先问变化发生在哪一层：评分器结果、生成行为、价值估计还是独立任务质量。奖励跳升而输出几乎未变，先检查评分配置；长度骤增且熵下降，再检查采样与更新。按证据缩小范围，比同时调学习率、奖励和提示更容易得到结论。

保留退化前后的相同任务回放十分有用。只看总体曲线，会掩盖某类工具错误突然增加；把两个版本的动作并排，就能观察策略是否改变了查证、重试或停止方式。

## 24.2 训练日志如何解释

先确认仪表盘上的数字究竟怎样计算。KL、熵和裁剪比例都依赖定义与统计范围；token 级与序列级裁剪比例放在一起，可能根本不在比较同一件事。价值解释方差也只提供一部分信息，不能单独证明 Critic 已足够准确。

KL 需要说明比较对象是本轮旧策略还是参考策略，也要说明是在何种前缀与 token 上统计。熵通常同样来自采样到的上下文，未覆盖的区域可能具有不同变化。指标的平均值提供线索，不等于完整行为描述。

裁剪比例高时，应再看优势正负与概率比方向。某些样本超出阈值并不意味着所有梯度都被截断；目标中的最小值结构决定实际激励。对日志作机械阈值判断，容易忽略这些细节。

## 24.3 区分训练与评估不确定性

同一配置重训几次，结果可能不同；同一模型换一批测试任务，分数也可能变化。前者主要反映训练不确定性，后者反映评估样本不确定性。报告区间时要说明重采样单位，同一主体衍生的多条任务还可能相关；完整结果比一个最佳种子更有说服力。[RL 统计评估研究](https://arxiv.org/abs/2108.13264v4)

比较两策略时，可在相同测试任务上配对记录成功与失败，观察哪些任务发生变化。若A新增成功十题，却同时丢掉原先八题，总分略升与全面改善具有不同含义。配对轨迹也便于寻找机制差异。

统计区间要与抽样结构一致。一个实体生成的许多相似任务，不应被轻易当作大量独立证据；多个检查点反复选择最优，也会增加乐观偏差。报告任务划分、种子与选择规则，才能让数字被正确理解。

## 24.4 离线评估能支持什么

离线策略评估（OPE）可使用重要性采样、价值估计或双重稳健方法，但依赖行为概率、覆盖或模型质量等条件。长轨迹权重可能高方差；缺乏重叠时，窄区间也可能只反映错误假设下的精确估计。高影响决策仍需进一步验证。

重要性采样需要恢复行为策略选择动作的概率，并要求目标行为得到足够覆盖。长轨迹上的概率乘积可能使少数样本占据巨大权重，得到表面上很不稳定的估计。价值模型方法减少部分权重问题，却增加模型正确性的依赖。

不同估计器结果分歧很大时，应检查其条件，而不只选择最乐观的一个。离线估计适合支持筛选与诊断；当覆盖不足时，它也可以诚实地告诉我们哪些策略暂时无法可靠比较。

## 24.5 最小评估记录

每个检查点记录固定任务集上的成功、成本与主要失败类型；每个种子保留完整结果；最终比较使用独立测试集，并注明检查点如何选择。

若只在同一批测试任务上反复挑选最优版本，这批任务实际上已参与模型选择。应另留最终测试，或明确将已有结果称为验证表现。排障用样本可以详细查看，最终测试则应控制暴露与复用。

最小报告还应保存失败分布：错误口径、遗漏证据、循环调用、过早停止、工具异常等各占多少。两策略平均成功率相近，却可能具有完全不同的风险与成本结构。

测试集内容一旦被用于奖励修订、提示设计或检查点选择，就参与了开发过程。应把这种使用记录下来，必要时建立新的留出集。评估可信度来自清楚的实验边界，不只是评分脚本运行成功。
